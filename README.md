需要 Node.js 24.15+（使用内置 SQLite）。

```sh
npm install
npm start
```

一次启动前端（5173）和课堂 API（3001）。也可以分别运行 `npm run dev` 和 `npm run server`。学生打开 http://localhost:5173/，教师打开 http://localhost:5173/teacher.html。点击“试试示例声音”可以体验三个合成敲击的自动切分；示例不会自动保存。

录音使用浏览器 MediaRecorder，必须在 HTTPS 或本机 localhost 下运行并授权麦克风。安卓通过普通局域网 HTTP 地址打开时通常无法录音。

局域网浏览器课堂使用 `npm run setup:https` 准备证书，再执行 `npm run classroom` 启动 HTTPS 生产服务。教师使用 `https://电脑IP:8443/teacher.html`，学生使用 `https://电脑IP:8443/`；首次连接打开 `http://电脑IP:8080/`，按指引下载并信任课堂 CA 公钥。脚本不会自动安装系统根证书。完整步骤、Windows 依赖、作品迁移与排查见 [局域网 HTTPS 部署说明](docs/lan-https.md)。浏览器的系统证书安装及各目标设备录音/拍照需独立验收；安卓 App 的已有局部真机结果不能代替浏览器验收。当前 iOS App 固定连接公开课堂，按其客户端说明使用。

不能使用浏览器的学生平板使用新增的 `android/` 普通安卓客户端。APK 内置课堂 CA 公钥，无需学生在浏览器安装证书；应用限制外部页面、新窗口和协议跳转，提供教师管理码、应用内拍照与受限文件操作。普通应用不能禁止 Home 或系统任务切换。构建、使用及尚未验收的边界见 [安卓学生客户端](docs/android-student.md)；2026-10-16～17 已开始小米真机局部验收，完整子项与版本证据见[安卓真机最小验收矩阵](docs/android-real-device-acceptance.md)，不据此标记可发布。

## 已实现

- 学生节奏圆点支持向右拖动增加时值、向左收回缩短及点击动画；每个时值块只触发一次，覆盖位置不重复触发。原声按原速从头播放：时值比录音长时后面留空，比录音短时只播放开头，到时停止；不拉伸、不变调、不淡化。时值长度随作品备份及教师审批同步。

- 学生节奏编创：点击声音图标进入二级页面，再打开“节奏编创”。支持 1–16 小节、16 个圆点、水滴拖动时值、原声播放、复制、循环试听和本地保存；节奏随备份保存，由教师接受后在下一遍完整 loop 启用。
- 学生安卓历史 0.4.0 测试包已构建，支持手机和平板及 ZXing 内嵌扫码、受控外部 JSON/照片分享；当前 0.4.1 / 5 的正式签名条件和受控测试边界见[安卓客户端](docs/android-student.md)。iPhone / iPad 支持系统限定类型文件导入导出，`0.3.0 (2026102101)` 已在外部 TestFlight 组“正在测试”，用户已确认安装后旧作品保留且试听正常；节奏提交与教师完整循环回听仍待验收，见 [iOS 客户端](docs/ios-student.md)。

- 最长 15 秒录音，自动停止并释放麦克风；切换到后台也结束录音。
- 自动识别多个声音起点，逐片试听；灵敏度重切分和手动选片。
- 波形支持鼠标和触摸拖动框选、拖动选区整体移动、拖动两端裁切，与下方精调滑块同步；保存采样最长 1 秒。切点应用 3 ms 淡入淡出减少爆音。
- 音频导入（浏览器支持的格式，最大 25 MB）；超过 15 秒只处理前 15 秒并提示。
- 基于 IndexedDB 的本地声音库，最多 200 份；命名、试听、重命名、删除、导出 WAV。
- v2 JSON 整库本地备份，包含声音、裁切照片及动漫形象，兼容 v1 声音备份；合并导入时相同 ID 跳过，新增作品超出 200 份或备份无效时整次拒绝，不部分写入。
- 学生填写姓名和 6 位课堂码连接课堂，无需密码，重名编号仅在系统内部保存。教师保留账号密码，使用随机盐 scrypt；双方使用各自的 HttpOnly 会话。
- 教师创建课堂（1–50 人）、课堂码与二维码、满员等待和人数扩容。
- 教师查看已入课、已收到作品、尚未提交、待处理更换和等待扩容统计；预览教室、厨房或操场环境。
- 按课堂人数生成编号预留位置；已入课学生分配稳定编号，作品留在等待区。教师拖动编号或使用方向键调整位置，服务器保存后刷新保持；扩容只新增位置，不移动旧位置。
- 学生选择本地声音提交；首次提交直接接收，更换需教师接受，未接受时原作品保留；重复请求不会重复写入。
- 教师查看本课堂成员及音频，试听、接受或拒绝最新更换；学生只能查看自己的提交。
- 教师节奏格子：每位学生一条轨道，固定 4/4、每小节 16 格、1–16 小节，支持点击、拖动和键盘编辑、复制到下一小节、清空本小节与收起界面。自动保存到 SQLite；失败可重试，过期版本不能覆盖其他窗口的编排。
- 统一 Web Audio 循环播放，只有播放/停止；实时调节 40–240 BPM、0–50% Swing、总音量与单角色音量。新伙伴下一遍加入、可以取消等待，退出立即生效。
- 格子编辑和接受的声音替换下一遍生效；长度在两遍循环边界改变，缩短删除尾部，扩大不恢复。舞台显示演奏角色、统一动作、loop 进度，并支持位置调整和全屏。
- 教师循环进度环、整遍进度条、逐小节进度与加入倒计时共用音频时钟，实时跟随速度和 Swing；声音列表显示叠加人数、声音名称和发声反馈。支持“全部加入／全部退出”，批量准备后同一 loop 起点加入。独立实现及来源说明见 [教师循环进度与声音叠加](docs/teacher-loop-mixing.md)。
- 待发送队列保存在 IndexedDB，按用户和课堂隔离。断线后可手动重试，连接恢复时自动发送。
- 平板和窄屏布局；麦克风拒绝、存储失败、无明显声音、无效备份均有提示。

自动切分使用短时能量和能量突增检测；环境噪声、连贯人声可能需要手动裁切。原始录音仅保留在当前页面内存，保存的采样进入本地库。每份作品可绑定照片草稿和生成的动漫形象。

## 数据和离线边界

作品保存在当前浏览器、当前网站来源下。清除网站数据、使用另一浏览器或更换端口不会自动共享作品，请使用备份导出与导入。达到 200 份时不自动删除旧声音。

页面已经加载后，声音采集、处理和保存不需要互联网。账号和课堂存储在运行服务的电脑 `data/classroom.sqlite` 中；数据库（含音频和账号）已加入 gitignore，不提交到 GitHub。服务重启保留记录。

局域网模式下，所有设备访问同一台电脑的前端地址，账号、课堂和音频由这台电脑的本地 API 统一处理；API 仅监听本机，由前端代理提供访问。没有互联网但本地服务可达时可正常使用课堂功能。

固定域名云部署使用独立的 `server/cloud.js`，由 Caddy 提供可信 HTTPS，WinSW 管理服务。课堂域名提供学生与教师页面，独立管理员域名只提供受保护的管理员功能，应用端口 3000 仍只监听本机；MCP 图片传输及本机凭证保存接口不公开。2026-10-19 启用基础公网课堂，2026-10-22 已更新统一业务程序，包含学生认证模块，但真实 Apple、微信、短信授权、旧设备作品迁移及完整真机课堂验收须按各自证据核对。云端更新保留原业务数据库和前后备份，不表示本机旧数据库已迁移。当前范围见 [课堂发布记录](docs/classroom-release-2026-10-22.md)，首次启用历史见 [公网启用记录](docs/public-network-launch-2026-10-19.md)。

网页服务不可达时，只显示上次缓存的身份与课堂记录，新的课堂码不能离线验证；可以准备待发送作品。恢复连接后重新验证真实登录会话，过期需要重新登录。缓存身份不能绕过服务端鉴权。首次注册或登录要求账号服务可达；尚未区分互联网账号和局域网身份服务。网页退出要求成功撤销服务端会话；iOS 退出立即清除本机课堂连接，并在服务可达时撤销会话，断网不阻止返回本地创作。

浏览器正式构建的“我的”显示“已准备离线创作”后，可离线重新打开、使用声音库、录音编辑和既有课堂记录。新课堂与首次连接仍需课堂服务；待发送作品在恢复连接并验证会话后发送。只缓存静态资源，私人课堂接口与素材不缓存；更新等待旧页面关闭后启用。

iOS 仅提供学生应用，界面随安装包提供：首次启动即可离线进入「我的声音库」，白底 Logo 代替加载信息。学生主动打开账号面板、登录，或填写姓名和课堂码点击「连接课堂」后才请求服务；退出或重新打开后恢复离线。教师使用独立网页。构建与验证见 [iPhone 学生客户端](docs/ios-student.md)。

离线缓存仅在 `npm run build` 的正式版本启用；`npm run dev` 不启用，以免缓存干扰开发。可执行 `npm run build`、`npm run preview -- --host 0.0.0.0`，先在电脑 localhost 验证。安卓仍需受信任的 HTTPS 才能使用录音和 Service Worker。浏览器安装入口由浏览器决定，PWA 安装及尚未覆盖的设备/版本冷启动仍需独立真机验收；已记录的 Android App 预缓存后冷开子项只覆盖矩阵所列配置。

蓝牙产品通道未实现；Bless/Bleak 的 GATT 对象与 9 项分片实验通过，尚未验证无线收发或接入课堂。教师已载入的声音在连接中断时继续循环，状态同步会重试；第一次开始演奏需要连接课堂服务。播放中接受更换保留旧素材，待新声音载入并到达下一遍 loop 后再确认切换。

节奏与角色坐标保存在课堂数据库。速度、Swing、音量及已选伙伴当前保留在页面会话中；停止会应用已载入的待生效修改，等待加入转为已选首轮。刷新页面或切换课堂停止演奏，不自动恢复播放。同一课堂只允许一个仍在报告状态的教师窗口控制演奏；状态每 5 秒同步，30 秒过期。

本地声音库目前按设备浏览器保存，不按登录账号分库；课堂列表、待发送队列和服务端访问权限按账号隔离。

## 体验账号与课堂

1. 打开 `/teacher.html`，在独立教师端注册教师账号，填写人数（默认 15、最多 50）和环境，创建课堂并记下 6 位课堂码。场景预览显示对应数量的编号位置。
2. 拖动编号布置位置，松手后等待“位置已保存”；也可用 Tab 选中编号，以方向键微调，Shift + 方向键扩大步幅。刷新页面验证位置保留。
3. 打开学生首页 `/`，在“我的”填写姓名和教师课堂码。同一浏览器的教师与学生入口使用独立会话；同一角色的多个标签页共享登录。
4. 学生录制／导入声音并保存，可绑定照片或形象，在课堂页面或声音库选择“提交到课堂”。教师在“作品等待区”查看并试听；上方统计随接收结果更新。
5. 学生再次提交时产生更换申请，教师可接受或保留原声音。学生的编号和预留位置保持不变。
6. 课堂满员后，新学生进入等待扩容名单；教师增加人数，按入课顺序分配新增名额，已有位置保持不变。
7. 在下方节奏格子中点亮每位学生的触发位置，按需增加小节。每次显示一个小节；点按切换触发，横向拖动设置长音区间，每个长音仅在起点触发一次。
8. 在声音舞台选择参与伙伴并播放。播放中新增伙伴等待下一遍，退出立即回等待区；音量、速度和 Swing 实时调整，停止后保留编排与已选伙伴。

课堂页面可见时约每 8 秒刷新，亦可手动刷新。布置预览中的编号与演奏舞台共用坐标；舞台仅显示正在参与的角色。等待区的音频控件用于单份作品试听，合奏由统一时钟调度。格子交互参考 [Groove Pizza](https://apps.musedlab.org/groovepizza/)。

HTTPS 生产入口的入课二维码使用配置好的局域网地址，即使教师在电脑上打开 localhost，也不会把 localhost 发给平板。开发入口的二维码仍使用当前访问地址。

`FREE_IMPRO_DB` 可指定课堂数据库文件，`API_PORT` 可修改开发 API 端口（启动前端时也传入同一值以配置代理）。`npm run classroom` 自动使用 Secure Cookie 和 HTTPS 来源校验；若自行使用反向代理，应设置 `COOKIE_SECURE=true` 并保留原始 Host 和 Origin。本地开发没有邮件验证、密码找回或学校统一身份接入；两个入口分别注册对应角色，每位教师只能管理自己创建的课堂。

## 学生形象与 EV生图储存库

2026-10-10 更新：当前应用通过图片申请队列配合教师的 ChatGPT Plus 网页聊天处理生图，不直接调用计费图像 API。所有生成操作使用 [EV生图储存库](https://chatgpt.com/g/g-p-6ac9c5efbfe4819180625b8121797b4f/project)，每位学生绑定一个长期对话，名称为 `姓名#内部编号 · 生图`；学生界面仍只显示姓名。同名学生的申请、额度和对话按内部账号隔离。

- 学生先离线录音、裁切、命名并保存声音；照片可以离线裁切并保存为草稿。
- 联网连接课堂后，在“我的”明确注册学生账号。仅输入姓名与课堂码入课的游客不能生图。
- 在“我的”拍摄或导入自己的正面照片，申请固定的 3D 动画风格静态形象。固定形象建立后不覆盖。
- 声音作品保存并命名后，可在二级形象页面申请配图，沿用固定学生形象并手持对应物品。
- 固定形象与作品配图共用每日一张额度，以北京时间换日。提交即预留额度，结果不明或申请结束不自动重复生成；跨日待处理申请仍需先完成，实际回传日也不允许收到第二张。
- 学生只显示“图像生成中”。固定形象自动保存，作品图片只绑定原作品；删除、改名和节奏编辑不会被迟到图片覆盖或复原。
- 本地照片、生成图片、声音和节奏可随原有整库备份保存。生成图片在 ChatGPT 项目的对应对话中留存，回传副本保存在学生本地；项目对话不是应用的独立图片存储 API。

教师进入独立网页 `/teacher.html`，打开“内部设置”：领取申请、查看参考图与提示，在 EV生图储存库 内创建或继续该学生对话。首次生成时粘贴实际对话地址，确认项目与学生身份并保存绑定，再导入生成结果。后续固定形象和作品配图沿用该地址；已绑定对话不能被其他学生复用或自动覆盖。服务器校验权限、具体 ChatGPT 对话地址和唯一绑定，项目归属仍需教师或浏览器执行者在网页中核实。

本地已提供官方 MCP SDK 的 `/mcp/images` 工具端点，以及支持 `document.modelContext` 的教师页面工具：查看申请、领取、读取参考、绑定学生对话、回传图片。端点令牌只允许处理当前教师的申请，有效 24 小时；创建新令牌撤销旧令牌。局域网 HTTPS 和开发代理均转发该端点。
