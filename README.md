# Free Impro · 学生声音创作与教师节奏合奏

当前已实现学生声音采集、本地作品库、账号与课堂提交、照片裁切及声音绑定，并接入 OpenAI 动漫形象接口。教师端支持课堂准备、作品等待区、节奏格子与核心循环合奏。声音仅在明确提交后传到本地课堂服务。

项目包含独立学生网页与安卓客户端，以及独立教师网页、安卓 APK、Windows/macOS 桌面客户端。教师各客户端连接同一课堂服务，安装包不内置服务端。详见 [教师客户端使用说明](docs/teacher-clients.md)。局域网 HTTPS 生产服务、证书准备和设备连接指引已实现；安卓测试 APK 已在本地构建并通过原生单元测试、Lint 错误检查与签名校验。真实图像生成、安卓真机与跨设备联调尚未验收，蓝牙尚未接入，15/50 人实际课堂负载仍需验证。完整需求及开发进度见 [designdocument.md](designdocument.md)。

## 本地启动

需要 Node.js 24.15+（使用内置 SQLite）。

```sh
npm install
npm start
```

一次启动前端（5173）和课堂 API（3001）。也可以分别运行 `npm run dev` 和 `npm run server`。学生打开 http://localhost:5173/，教师打开 http://localhost:5173/teacher.html。点击“试试示例声音”可以体验三个合成敲击的自动切分；示例不会自动保存。

录音使用浏览器 MediaRecorder，必须在 HTTPS 或本机 localhost 下运行并授权麦克风。安卓通过普通局域网 HTTP 地址打开时通常无法录音。

平板课堂使用 `npm run setup:https` 准备证书，再执行 `npm run classroom` 启动 HTTPS 生产服务。教师使用 `https://电脑IP:8443/teacher.html`，学生使用 `https://电脑IP:8443/`；首次连接打开 `http://电脑IP:8080/`，按指引下载并信任课堂 CA 公钥。脚本不会自动安装系统根证书。完整步骤、Windows 依赖、作品迁移与排查见 [局域网 HTTPS 部署说明](docs/lan-https.md)。安卓真实证书安装、录音与拍照仍需真机验收。

不能使用浏览器的学生平板使用新增的 `android/` 普通安卓客户端。APK 内置课堂 CA 公钥，无需学生在浏览器安装证书；应用限制外部页面、新窗口和协议跳转，提供教师管理码、应用内拍照与受限文件操作。普通应用不能禁止 Home 或系统任务切换。构建、使用及尚未验收的边界见 [安卓学生客户端](docs/android-student.md)。

## 已实现

- 最长 15 秒录音，自动停止并释放麦克风；切换到后台也结束录音。
- 自动识别多个声音起点，逐片试听；灵敏度重切分和手动选片。
- 波形支持鼠标和触摸拖动框选、拖动选区整体移动、拖动两端裁切，与下方精调滑块同步；保存采样最长 1 秒。切点应用 3 ms 淡入淡出减少爆音。
- 音频导入（浏览器支持的格式，最大 25 MB）；超过 15 秒只处理前 15 秒并提示。
- 基于 IndexedDB 的本地声音库，最多 200 份；命名、试听、重命名、删除、导出 WAV。
- v2 JSON 整库本地备份，包含声音、裁切照片及动漫形象，兼容 v1 声音备份；合并导入时相同 ID 跳过，新增作品超出 200 份或备份无效时整次拒绝，不部分写入。
- 学生／教师账号注册、登录、退出；服务端密码使用随机盐 scrypt，登录会话放在 HttpOnly Cookie 中。
- 教师创建课堂（1–50 人）、课堂码与二维码、满员等待和人数扩容。
- 教师查看已入课、已收到作品、尚未提交、待处理更换和等待扩容统计；预览教室、厨房或操场环境。
- 按课堂人数生成编号预留位置；已入课学生分配稳定编号，作品留在等待区。教师拖动编号或使用方向键调整位置，服务器保存后刷新保持；扩容只新增位置，不移动旧位置。
- 学生选择本地声音提交；首次提交直接接收，更换需教师接受，未接受时原作品保留；重复请求不会重复写入。
- 教师查看本课堂成员及音频，试听、接受或拒绝最新更换；学生只能查看自己的提交。
- 教师节奏格子：每位学生一条轨道，固定 4/4、每小节 16 格、1–16 小节，支持点击、拖动和键盘编辑、复制到下一小节、清空本小节与收起界面。自动保存到 SQLite；失败可重试，过期版本不能覆盖其他窗口的编排。
- 统一 Web Audio 循环播放，只有播放/停止；实时调节 40–240 BPM、0–50% Swing、总音量与单角色音量。新伙伴下一遍加入、可以取消等待，退出立即生效。
- 格子编辑和接受的声音替换下一遍生效；长度在两遍循环边界改变，缩短删除尾部，扩大不恢复。舞台显示演奏角色、统一动作、loop 进度，并支持位置调整和全屏。
- 待发送队列保存在 IndexedDB，按用户和课堂隔离。断线后可手动重试，连接恢复时自动发送。
- 平板和窄屏布局；麦克风拒绝、存储失败、无明显声音、无效备份均有提示。

自动切分使用短时能量和能量突增检测；环境噪声、连贯人声可能需要手动裁切。原始录音仅保留在当前页面内存，保存的采样进入本地库。每份作品可绑定照片草稿和生成的动漫形象。

## 数据和离线边界

作品保存在当前浏览器、当前网站来源下。清除网站数据、使用另一浏览器或更换端口不会自动共享作品，请使用备份导出与导入。达到 200 份时不自动删除旧声音。

页面已经加载后，声音采集、处理和保存不需要互联网。账号和课堂存储在运行服务的电脑 `data/classroom.sqlite` 中；数据库（含音频和账号）已加入 gitignore，不提交到 GitHub。服务重启保留记录。

同一 Wi-Fi 内，所有设备必须访问同一台电脑的前端地址，账号、课堂和音频由这台电脑的本地 API 统一处理；API 仅监听本机，由前端代理提供访问。没有互联网但本地服务可达时可正常使用课堂功能；本实现没有云端账号服务。

服务不可达时，只显示上次缓存的身份与课堂记录，新的课堂码不能离线验证；可以准备待发送作品。恢复连接后重新验证真实登录会话，过期需要重新登录。缓存身份不能绕过服务端鉴权。首次注册或登录要求账号服务可达；尚未区分互联网账号和局域网身份服务。退出必须成功撤销服务端会话，断网时提示恢复连接再退出。

正式构建已加入 Web App Manifest 与离线页面缓存。首次成功打开后，页脚显示“已准备离线创作”，之后可以离线重新打开、使用本地声音库、录音编辑及查看曾加入的课堂。新课堂和首次登录仍需连接服务，离线准备的提交在连接恢复并验证真实登录后发送。只缓存静态页面和脚本，不缓存账号/课堂接口或私人素材下载接口。新版本等待旧页面关闭后启用，不在课堂中途自动刷新。

离线缓存仅在 `npm run build` 的正式版本启用；`npm run dev` 不启用，以免缓存干扰开发。可执行 `npm run build`、`npm run preview -- --host 0.0.0.0`，先在电脑 localhost 验证。安卓仍需受信任的 HTTPS 才能使用录音和 Service Worker。浏览器安装入口由浏览器决定，安卓安装和离线冷启动尚需真机验收。

蓝牙未实现。教师已载入的声音在连接中断时继续循环，状态同步会重试；第一次开始演奏需要连接课堂服务。播放中接受更换保留旧素材，待新声音载入并到达下一遍 loop 后再确认切换。

节奏与角色坐标保存在课堂数据库。速度、Swing、音量及已选伙伴当前保留在页面会话中；停止会应用已载入的待生效修改，等待加入转为已选首轮。刷新页面或切换课堂停止演奏，不自动恢复播放。同一课堂只允许一个仍在报告状态的教师窗口控制演奏；状态每 5 秒同步，30 秒过期。

本地声音库目前按设备浏览器保存，不按登录账号分库；课堂列表、待发送队列和服务端访问权限按账号隔离。

## 验证

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run test:offline
npm run test:https
```

也可使用本机已安装的 Chrome：`PLAYWRIGHT_CHANNEL=chrome npm run test:browser`。浏览器测试包含声音流程和两套独立账号的课堂流程；尚未进行安卓真机测试。

浏览器测试使用独立的 4174/3002 端口和临时 SQLite 数据库，不复用开发服务及正式课堂数据。测试结束后关闭测试服务。

单元和接口测试覆盖声音处理、本地容量、布局迁移、节奏持久化与冲突、审批和循环边界。浏览器测试覆盖学生原有流程，以及教师格子编辑、合奏、加入退出、实时参数和播放中替换。50 声部时序使用模拟时钟，50 轨布局使用快照数据；这些测试不替代安卓录音、50 台设备传输或实际音画同步验收。

本轮验证通过：48 项单元/接口、29 项浏览器回归、1 项 HTTPS 课堂流程、1 项正式构建离线冷启动、1 项桌面集成流程及 8 项原生 Java 测试，以及生产构建和双端 APK 构建。实际 macOS Apple Silicon 打包应用已通过登录和创建课堂测试；Windows 与 Intel Mac 包尚未实机运行。双端 Android Lint 均为零错误（学生 5 项提示，教师 1 项提示）。覆盖录音与相机权限等待期间退后台、迟到授权释放、导出失败清理，以及教师编排、并发审批、断线演奏和离线恢复。测试使用临时课堂数据；安卓安装、实际 WebView 和文件恢复仍需真机验收。

## 体验账号与课堂

1. 打开 `/teacher.html`，在独立教师端注册教师账号，填写人数（默认 15、最多 50）和环境，创建课堂并记下 6 位课堂码。场景预览显示对应数量的编号位置。
2. 拖动编号布置位置，松手后等待“位置已保存”；也可用 Tab 选中编号，以方向键微调，Shift + 方向键扩大步幅。刷新页面验证位置保留。
3. 打开学生首页 `/` 注册学生账号，输入课堂码。同一浏览器可同时登录教师和学生，两个入口使用独立会话；同一角色的多个标签页仍共享登录。
4. 学生录制／导入声音并保存，可绑定照片或形象，在课堂页面或声音库选择“提交到课堂”。教师在“作品等待区”查看并试听；上方统计随接收结果更新。
5. 学生再次提交时产生更换申请，教师可接受或保留原声音。学生的编号和预留位置保持不变。
6. 课堂满员后，新学生进入等待扩容名单；教师增加人数，按入课顺序分配新增名额，已有位置保持不变。
7. 在下方节奏格子中点亮每位学生的触发位置，按需增加小节。每次显示一个小节；拖动从点亮格开始会擦除，从空格开始会连续点亮。
8. 在声音舞台选择参与伙伴并播放。播放中新增伙伴等待下一遍，退出立即回等待区；音量、速度和 Swing 实时调整，停止后保留编排与已选伙伴。

课堂页面可见时约每 8 秒刷新，亦可手动刷新。布置预览中的编号与演奏舞台共用坐标；舞台仅显示正在参与的角色。等待区的音频控件用于单份作品试听，合奏由统一时钟调度。格子交互参考 [Groove Pizza](https://apps.musedlab.org/groovepizza/)。

HTTPS 生产入口的入课二维码使用配置好的局域网地址，即使教师在电脑上打开 localhost，也不会把 localhost 发给平板。开发入口的二维码仍使用当前访问地址。

`FREE_IMPRO_DB` 可指定课堂数据库文件，`API_PORT` 可修改开发 API 端口（启动前端时也传入同一值以配置代理）。`npm run classroom` 自动使用 Secure Cookie 和 HTTPS 来源校验；若自行使用反向代理，应设置 `COOKIE_SECURE=true` 并保留原始 Host 和 Origin。本地开发没有邮件验证、密码找回或学校统一身份接入；两个入口分别注册对应角色，每位教师只能管理自己创建的课堂。

## 照片与动漫形象

在声音库选择“制作形象”，或进入“声音形象”选择一份已保存的声音。浏览器版可用“拍一张照片”调用系统相机，也可导入 JPG、PNG、WebP（最大 10 MB）；专用安卓客户端改用应用内相机，暂不开放系统相册。通过拖动、缩放和位置滑块选定主体。裁切图保存为 256 × 256 PNG。

- 不联网也能裁切并保存照片草稿，草稿明确标为照片，不冒充动漫形象。
- 生成前需要登录。点击生成才会把裁切图发送给 OpenAI；原始照片和声音不会发送给生成服务。
- 生成的形象采用统一提示词，请求透明 PNG；重新生成失败时保留原形象。修改照片或裁切会清除当前编辑中的旧生成结果，避免图片与主体不匹配；已保存作品不受影响，直到再次保存。
- 本地声音作品绑定一张裁切照片和一个可选动漫形象，不额外占用 200 份名额。修改本地形象不会自动改变已提交课堂作品，需要再次提交并遵循更换审批。
- 课堂只接收作品用于展示的动漫形象（无形象时使用带明确标注的照片草稿）及声音；原裁切照片不会在存在生成形象时一并提交。
- 整库 JSON 备份升级为 v2，包含声音、裁切照片和生成形象，同时兼容 v1 声音备份；导入上限 250 MB。

### 配置 OpenAI

项目根目录的 `.env` 仅留在本地（已加入忽略规则）。可参考 `.env.example`：

```dotenv
OPENAI_API_KEY=你的服务器API密钥
OPENAI_IMAGE_MODEL=gpt-image-2.5-flare
```

填写后重新启动 `npm run server`（或重启 `npm start`）。不要使用 `VITE_OPENAI_API_KEY`，不要将真实密钥放进前端或提交到 GitHub。默认模型及 `images/edits` 参数依据 [OpenAI 官方图像生成文档](https://developers.openai.com/api/docs/guides/image-generation)。模型访问权限及额度取决于你的 API 项目。

接口使用单张图片、1024 × 1024、中等质量、透明 PNG。客户端将生成图片缩小到 256 × 256 存储。每个账号最多同时生成一次，服务最多三个并发，每账号每小时最多 10 次尝试（内存限额，服务重启后重置）。失败不会自动反复调用计费接口；取消等待可能无法撤销已经产生的服务用量。

本次未配置真实 API 密钥，尚未执行真实 OpenAI 生成。测试使用显式模拟的供应商响应，验证请求格式、鉴权、失败保留、图片绑定、课堂传输和备份恢复。实际画风与安卓相机效果需配置密钥后进行真机验证。

## 教师独立应用

教师网页入口是 `/teacher.html`，学生入口是 `/`；两端身份、页面与原生应用包独立，课堂数据由同一个服务管理。请通过运行中的服务访问网页，不要直接双击 HTML 文件。

```sh
npm run teacher:desktop
npm run package:teacher:mac
npm run package:teacher:windows
node scripts/teacher-desktop.js package darwin x64
npm run test:desktop
```

本地安装包和使用步骤见 [教师客户端使用说明](docs/teacher-clients.md)。学生 APK 同步升级为 0.2.0，适配独立学生 API 与离线缓存。当前安装包是测试版本，正式签名、macOS 公证、安卓与 Windows 实机验收尚未完成；源码与文档已同步到 GitHub，测试安装包仍只保存在本地。
