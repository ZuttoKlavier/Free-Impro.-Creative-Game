# 教师循环进度与声音叠加

日期：2026-10-06。入口为独立教师网页 `/teacher.html`，进入课堂后的声音舞台。

## 参考与实现范围

参考用户指定的 [Incredibox 官方演示](https://www.incredibox.com/demo/) 和官方描述的角色音乐叠加体验。公开页面可以观察，不等于其业务代码可以复用；[官方使用条款第 6 节](https://www.incredibox.com/info/gtu) 明确限制源码提取与移植。本轮没有复制、解混淆或接入其业务脚本、音频、角色、图标，也不使用来源不明的非官方移植仓库。

正式实现延续本项目已有的 Web Audio 调度器，以本项目代码、SVG 和 CSS 增强教师体验，没有添加第三方依赖或运行时 CDN。Incredibox 的固定预制声音不替代学生自己的声音和教师可编辑的节奏。

## 教师可以使用的功能

- 循环进度环与进度条同步显示当前完整 loop，每遍结束回到起点后继续循环。
- 每个小节单独标记进度，四拍拍点显示当前拍；仍为 4/4、16 个位置／小节、1–16 小节。
- “距下一遍”显示剩余秒数；有等待声部时同时显示等待人数及加入倒计时。
- 声部列表显示学生、声音名称、参与状态和单独音量；声音触发时该层指示和舞台角色一起反馈。指示是触发动画，不是实际电平表。
- “全部加入”最多同时载入四份声音，准备完成后一起进入下一遍；开始播放前则预选首轮，不会自动播放。
- 载入时可取消单个声部或全部退出；载入失败的声音提示单独重试，其余声部仍可加入。
- “全部退出”立即清除全部在场与等待声部，循环继续运行，直至点击停止。

## 同步规则

音频源通过各自的 GainNode 汇入共同总音量及限幅器，所有触发使用一个 AudioContext 的时间，而不是为每个声音开启独立播放计时器。批量加入只提交一次状态和调度修改，因此本次准备好的声部共享同一个循环边界。

进度和剩余秒数从已经实际到达的音频步骤推算，不采用预先排入的下一遍时间作为当前界面位置。剩余秒数包含当前步骤余量和后续步骤的 Swing 长短分配，调整 BPM 或 Swing 后重新计算。等待加入仍在下一遍完整 loop 起点生效；小节数继续按已确认的两遍边界规则改变。声音的 playbackRate 保持 1，长音使用原有保持音高处理。

本轮未新增暂停、拖动跳播、自动停止、服务器播放、学生远程扬声器同步或跨设备音频时钟。iOS 仍仅包含学生界面。

## 验证边界

本轮生产构建通过；58 项单元／接口测试和 11 项 Chrome 浏览器测试通过。浏览器范围包含教师合奏、真实音频渲染、载入时批量取消、窄屏 16 小节以及 iOS 学生离线创作回归。测试使用隔离课堂数据。

时序测试覆盖 1、8、16 小节和不同 Swing 的倒计时、实时 BPM 调整、预调度不提前切换、50 个声部在共同边界叠加、批量退出和取消。

浏览器使用真实 Web Audio。界面测试通过 Chrome 的 [无扬声器输出接口](https://developer.chrome.com/blog/audiocontext-setsinkid/) 保持原生音频时钟推进，不依赖本机音频设备；这个设置只在测试中启用。正式应用继续使用正常声音输出。另用 OfflineAudioContext 渲染真实音频源与增益图，核对叠加前后样本值、单层音量和退出后其他声部保持播放；该项隔离验证混音，不包括总输出限幅器的听感验收。

真实扬声器、50 人实际素材、设备负载和长时间课堂听感仍需现场验收。
