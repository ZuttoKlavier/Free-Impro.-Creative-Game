## 4. 前轮五个实现缺口已修复

1. **安卓连接设置（A28）**：“我的”提供可达入口，调用原生管理码验证；初次取消配置不会留下无入口页面。
2. **受控外部备份（A04/A27）**：Android 从授权分享接收 JSON；iOS 通过系统限定类型窗口保存/导入，保留旧私有备份。实际卸载重装仍待真机。
3. **安卓脚本失效兜底**：监听页面就绪，主页面或脚本失败后可用原生下拉重连；页面恢复就绪后交还网页手势。
4. **拒绝节奏 revision（A31）**：在事务内核对当前编排版本、申请和声音，过期返回 409；重复及竞争审批覆盖通过。
5. **舞台旁等待区（6.3）**：与真实演奏舞台共同布局，全屏仍能处理新作品，窄屏无横向溢出。

本轮还修复照片/形象错绑、重复恢复覆盖、跨标签页删除后漏恢复、原生选择/权限迟到回调、系统保存取消误报、快速停止重播、重复审批及旧回包覆盖新申请。详见 [修复与验证记录](github-completion-integration.md)。测试后源码复核与回归通过不保证没有其他 bug。
