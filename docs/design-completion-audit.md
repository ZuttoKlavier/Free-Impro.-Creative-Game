## 4. 本次确认的实现缺口

1. **安卓连接设置不可达（A28）**：[`MainActivity.java`](../android/app/src/main/java/org/freeimpro/student/MainActivity.java) 第 42–43 行隐藏顶部工具栏，`verifyAdmin()` 仅定义未调用；[`src/main.js`](../src/main.js) 第 110–113 行只为 iOS 添加“连接设置”。首次配置后无法在现界面修改教师地址或管理码。
2. **原生跨安装备份恢复不完整（A04/A27）**：安卓文件列表仅本安装导出的文件；[`ios/LocalFiles.swift`](../ios/LocalFiles.swift) 的导出留在排除系统备份的私有目录，卸载后不能靠这些文件恢复。需要受控外部导出/导入流程。
3. **安卓脚本失效兜底缺失**：`MainActivity.java` 第 45–56、72–80 行只依赖 `mainPageFailed`，没有检测成功加载后的脚本就绪失败；与 2026-10-03 下拉刷新要求不一致。
4. **拒绝节奏未检查编排版本（A31）**：[`server/arrangement.js`](../server/arrangement.js) 第 101 行直接拒绝；接受分支才通过 `edit()` 校验 revision。过期页面可以拒绝仍是当前的申请，但不能覆盖新申请或更改轨道。应补校验，或由产品确认后明确规则仅约束接受。
5. **真实舞台和等待区未相邻（6.3）**：`src/classroom.js` 第 183 行分别拼接准备区、舞台和格子；相邻网格只存在于准备区。需要把等待区与实际演奏舞台共同布局。

以上均只是本次核对记录，本次未修改功能代码来宣称缺口已经修复。
