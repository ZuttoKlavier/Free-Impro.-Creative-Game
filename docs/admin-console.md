# 后台管理员

2026-10-13：新增独立中文管理员控制台，使用同一份课堂 SQLite 数据库。后台可以跨教师查看服务器数据，不改变教师只能管理自己课堂的权限。管理员与教师、学生使用不同账号表和登录会话。

## 入口和首次配置

已运行的本机 HTTPS 服务入口：`https://127.0.0.1:8443/api/admin/console`。开发入口：`http://localhost:5173/admin.html`。`/api/admin/console` 由服务端直接提供，在只转发 `/api/` 的部署中也可使用；`/admin.html` 随网页构建提供，不依赖学生或教师页面。

服务电脑执行：

```sh
npm run admin:database:install
npm run admin:setup
```

数据库浏览器需要 Python 3。安装到 `data/admin/venv`，不替换系统 Python；确切依赖版本保存在 `requirements/admin-database.txt`。普通账号管理页面使用现有 Node 服务，数据库浏览器按需启动。

初始化命令要求交互输入管理员账号和至少 12 位密码，不回显密码。同账号重新初始化会更新密码并撤销原管理员会话。没有公开的管理员注册接口，也没有内置默认密码。可用 `npm run admin:setup -- --generate` 创建随机密码，首次登录信息仅保存到本机 `data/admin/initial-login.txt`；已有文件或管理员存在时拒绝覆盖。Unix 文件权限为 600，Windows 服务目录应沿用部署规定的受限 ACL。凭证、数据库、Python 环境及截图均不进入 GitHub。

`FREE_IMPRO_DB` 决定操作哪份数据库；初始化和运行服务必须使用同一个值。管理员功能随课堂服务启动，不需要再开放数据库端口。正式环境通过课堂原有的 HTTPS 入口使用，管理员登录 Cookie 设置 HttpOnly、SameSite=Strict 和 Secure，有效期八小时。

## 管理范围

- 概览所有教师、学生、课堂、作品提交和图片申请，按表、身份、文本搜索，每页 25 条。
- 新增教师或学生，修改姓名，重置密码，退出所有登录。重置密码或撤销会话同时撤销该教师的生图工具凭证。
- 修改课堂和作品提交名称，取消待处理或处理中的图片申请。
- 删除教师、学生、课堂或作品提交，明确二次确认后在事务中清理相关数据。教师删除会删除其课堂；课堂删除保留教师和学生账号。关联课堂正在演奏时拒绝删除，须先在教师端停止。
- 查看所有 15 张原业务表和 3 张管理员表，包括节奏、成员、形象、对话关联和管理操作记录。密码、盐、会话令牌、工具凭证摘要和图片领取凭据不作为可见字段。
- 下载受管理员鉴权保护的音频或图片。普通列表和 JSON 导出只包含二进制长度、类型和下载地址，不把音频、图片整块塞入表格。
- 导出全部匹配记录的 JSON，最多一万条、8 MiB。更大的结果需缩小搜索范围；导出采用单次有界查询，避免反复扫描和阻塞课堂请求。

服务器仅保存已经提交或同步到课堂的数据。各设备 IndexedDB 中尚未提交的离线作品无法由后台直接访问。管理员密码和会话也不通过学生或教师接口开放。

高级数据库浏览接入 GitHub 的 [coleifer/sqlite-web](https://github.com/coleifer/sqlite-web) 0.8.2，直接读取当前数据库，支持表结构、分页、只读 SQL 和 CSV/JSON 导出。账户和业务写入由中文后台的受控接口完成，防止任意 SQL 绕过课堂、图片额度与关联约束。原始数据库下载、结构修改、任意文件或数据库加载关闭，秘密字段读取同样受 SQLite authorizer 遮蔽。配置、上游来源和 MIT 归因见 [数据库浏览器接入说明](admin-database-upstream.md)。
