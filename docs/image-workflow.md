# EV生图储存库与学生专属对话

更新：2026-10-10。当前方案使用教师的 ChatGPT Plus 普通网页聊天；软件不自动调用付费图像 API。

## 使用流程

1. 学生离线录音、裁切、命名并保存声音。拍照草稿同样可离线保存。
2. 输入姓名与课堂码连接课堂，在“我的”注册生图学生账号。只入课的游客没有生图资格。
3. 申请固定学生形象：学生提交自己的裁切照片，服务器保存申请，界面显示“图像生成中”。固定形象为统一 3D 动画风格的静态图片。
4. 教师打开独立网页的“内部设置”，领取申请并查看参考图、提示及该学生的内部账号。
5. 所有生成都在 [EV生图储存库](https://chatgpt.com/g/g-p-6ac9c5efbfe4819180625b8121797b4f/project) 内完成。首次为学生创建 `姓名#内部编号 · 生图` 对话，保存网页实际显示的对话地址，并确认它属于此学生且位于该项目。以后继续同一对话。
6. 教师导入结果，服务器检查权限与额度，学生自动缓存固定形象。随后在额度允许的日期，可以为已命名声音申请持物配图，参考图按固定形象、物品照片的顺序提供。

## 保存与权限

- 服务器使用 SQLite 保存注册资料、申请、每日额度和唯一对话绑定。服务重启不会重置每日记录。
- 固定形象与作品配图共用北京时间每日一张。提交申请即预留当日额度；结果不明时不自动重发，领取重试返回原领取编号，不代表允许再次生成。结束申请不释放当天记录；迟到结果也占用回传日额度。
- 每个学生只保留一个对话绑定，一个对话只能属于一个学生；同名学生按内部账号区分。既有绑定不能自动改写，绑定教师以外的教师不能复用其对话。
- 服务器只接受无凭据、无查询参数的 `https://chatgpt.com` 具体对话地址，以及固定 EV 项目地址。它不能单凭地址证明项目归属，需教师或浏览器执行者检查网页。仅保存链接不等于已经创建对话或生成图片。
- 学生接口不返回外部项目、对话地址、内部对话标题或教师工具令牌。iOS 学生容器仅增加受控课堂接口，继续禁止外部网页、教师页面和 MCP 路由。
- ChatGPT 生成结果留在项目对应对话中，软件回传副本存到学生本地。原始申请照片在完成或结束后从课堂服务删除；ChatGPT 中的上传记录按其网页功能管理。
- 迟到作品图片通过本地事务绑定原作品及账号；改名、声音和节奏保留，删除或已替换的申请不会被旧结果覆盖。照片草稿和结果可随原有作品备份导出。

## 工具接入

官方 MCP SDK 提供 `/mcp/images` 的 Streamable HTTP 端点。教师在内部设置签发 24 小时令牌，令牌只处理自己的课堂申请，轮换撤销旧令牌，数据库只保存令牌摘要。

| 工具 | 作用 |
| --- | --- |
| `get_image_connection_status` | 查看权限范围内的连接活动、到期时间与申请数量，不代表自动生图已接通 |
| `list_image_requests` | 查看本教师的申请，不触发生图 |
| `claim_image_request` | 领取申请并保留 UUID 领取编号，重复领取不能再次生图 |
| `get_image_request` | 返回提示、参考图、EV 项目及既有学生对话 |
| `bind_student_conversation` | 核实网页后绑定实际学生对话地址 |
| `return_generated_image` | 校验并回传一张 PNG，学生同步保存 |

支持 `document.modelContext` 的教师网页还注册同名页面工具，并沿用教师会话权限。开发代理和生产局域网 HTTPS 服务均转发 MCP 端点，HTTP 证书设置端口不提供 MCP。

2026-10-11 增加官方 SDK stdio 本机桥接、教师自动刷新与连接活动检测，可交由 OpenAI 官方安全隧道访问，无需公开课堂端口。详见 [本机隧道连接说明](teacher-image-tunnel.md)。

**尚未完成：**真实 Platform 隧道配置与 ChatGPT 插件授权、实际图片生成、无人值守网页操作与自动结果回传。本地 MCP 测试成功不证明这些连接已经完成。Plus 登录不能用作官方图像 API 授权，见 [官方限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)；网页版插件安装方式见 [官方 MCP 指南](https://learn.chatgpt.com/docs/extend/mcp)。不保存 Plus 密码、网页 Cookie 或访问令牌到课堂软件。
